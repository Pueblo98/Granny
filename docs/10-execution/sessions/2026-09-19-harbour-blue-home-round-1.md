# Session — Harbour Blue Home composition round 1

## Scope and authority

Simon requested one bounded mockup-only checkpoint in the primary root checkout
under the 2026-09-19 local mockup exception. The authorized output was four
full-screen Home-load directions plus a comparison and local documentation,
using the selected Harbour Blue board, SCR-003, CMP-007/010/011 and the active
Context Rooms direction.

This session did not authorize frontend code, Android work, Figma authoring,
real/persistent data, a complete room catalog, a selected winning composition,
Git branch/PR publication or changes to private Obsidian settings. Existing
dirty and untracked work was preserved.

## What changed

- Added round 1 with four 1586 × 992 PNG directions and a labeled 2 × 2
  comparison sheet. That local intermediate artifact folder is not retained in
  the consolidated checkout.
- Recorded the exact built-in image-generation prompts, selected source image,
  structural theses, sacrifices, omissions and fidelity limits beside local
  embeds.
- Linked the round from the mockup gallery and current milestone. The style-board
  index was not changed because it owns palette-board history; this round applies
  the selected board rather than reopening that iteration series.
- Kept all content fictional. No real names, private data, credentials,
  watermark or research claim appear in the generated images.

## Evidence

The selected Harbour Blue reference and every saved individual PNG were opened
at original detail. All required copy is visibly present and correctly spelled;
each screen has one written Menu, one written Rooms route, the Round composer,
Type a request, Ask me anything…, Talk and Send. A has no context region, B and
D each have exactly one written Kitchen entry, and C has exactly one fictional
continuation panel. No idle Stop, room grid, second room, prompt chips, bottom
navigation or unrelated dashboard content appears.

The image model approximates rather than certifies the named fonts, exact hex
pixels, target dimensions or focus geometry. Inspection noted variation in
invitation scale, richer-than-minimal pantry detail in B and strong portrait
weight in D. The comparison is a generated review overview, not a pixel-exact
montage. Android dp/sp, reflow, TalkBack, keyboard/switch order, IME behavior,
contrast on actual implementation and human comprehension remain unrun.

Repository validation and Obsidian-open evidence are recorded at handoff after
the requested maintenance commands complete.

## Handoff

The requested round is ready for Simon's visual review on local `main` under
the explicit mockup exception; it is not committed, pushed or merged. The next
bounded question is which direction to refine, or which restrained parts to
combine without creating a busier fifth design. Only after that choice should
the exact Home structure extend to a calm Rooms library, Kitchen, Fitness,
direct browse/search and room creation while preserving Harbour Blue and the
same composer.
