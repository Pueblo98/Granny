# Figma Working Agreement

Figma contains visual exploration and prototype artifacts. The repository retains product reasoning, requirements, behavior, decisions, and implementation contracts.

## Proposed file pages

1. `00 Cover & status`
2. `01 Foundations` — explored type, color, spacing, motion, accessibility.
3. `02 Components` — variants and states.
4. `03 Core journeys` — flows keyed to `J-###` and `UC-###`.
5. `04 Prototypes` — reviewable scenarios.
6. `05 Experiments` — explicitly non-canonical alternatives.
7. `99 Archive` — superseded work with dates.

## Handoff rule

A Figma link is not a complete specification. Approved visual choices must update this repository's design documents/tokens, identify affected requirements/use cases, include interaction and accessibility states, and state which Figma frame/version was reviewed. Store links only after a Figma file exists.

## First exploration

After scope review, design the home/listening states and J-001/J-002. Explore 3–4 warm, calm visual directions before choosing brand values. Include large-text, TalkBack semantics notes, touch-only, voice-only, error, uncertainty, confirmation, stop, and offline states.
