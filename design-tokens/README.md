# Design Token Schema

This directory will hold machine-readable design values after visual exploration and review. No final brand values are approved.

Planned token groups: semantic color, typography, spacing, radius, component dimensions, and motion. Tokens should use role-based names, record status/source, and map consistently into Figma and implementation. Do not insert arbitrary placeholder hex codes that could be mistaken for a selected palette.
